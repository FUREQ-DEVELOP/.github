# FUREQ-DEVELOP Organization Configuration

FUREQ-DEVELOPの公開Organization設定を管理するリポジトリです。

## 管理対象

- Organization公開プロフィール
- 共通Issueテンプレート
- 共通Pull Requestテンプレート
- 公開開発情報
- コミュニティ向けガイドライン

## 開発理念

- Fun：楽しさ
- Uniqueness：独自性
- Replayability：何度でも遊びたくなる魅力
- Excitement：ワクワク、興奮
- Quest：探求

## 注意事項

このリポジトリは公開されています。内部仕様、認証情報、未公開ゲームの情報は登録しないでください。

## 開発状況

開発基盤構築中。

## 利用方法

- 作業は `main` からブランチを作成し、Pull Requestで提案してください。
- タスクはGitHub Issues / Projectsで管理します。
- 変更の責務: .github。担当Team: `Shared-Services`。
- 依存関係や開発状況は [DevelopmentDocs](https://github.com/FUREQ-DEVELOP/DevelopmentDocs) を参照してください。
